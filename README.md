# Booking Behaviour and Revenue Leakage in Bangladesh's Hospitality Sector

A data-driven exploratory analysis of booking trends, cancellation risk prediction, and guest feedback sentiment across room categories.

## Dataset
[Hotel Booking Details (Kaggle)](https://www.kaggle.com/datasets/reportgg/hotel-booking-details). Download it and place it in `data/raw/`.

## Objectives
- Explore booking trends by season, channel, and room category
- Predict cancellation risk
- Analyse guest feedback sentiment per room category
- Estimate revenue leakage from cancellations
